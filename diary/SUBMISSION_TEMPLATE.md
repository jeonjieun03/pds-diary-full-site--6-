# 제출문 (템플릿 — 실제로 써보신 뒤 채워주세요)

## 짧은 확인 방법 (4줄)
1. 어디로 가나요: (결과물 URL을 새 시크릿 창에 붙여넣습니다)
2. 세 단계 안에 무엇을 하나요: (예: ① '할 일' 탭에서 할 일 하나를 '완료로 표시' → ② 시작/끝 시각과 실제 시간을 입력해 저장 → ③ '돌아보기' 탭에서 완료 숫자가 올라갔는지 확인)
3. 무엇이 보이면 통과인가요: (예: 돌아보기의 '완료' 숫자가 1 늘고, 그 숫자를 누르면 방금 완료한 할 일이 목록에 뜬다)
4. 안 될 때는 무엇이 보이나요: 화면 위쪽에 "데이터를 불러오지 못했습니다..." 라는 오류 배너가 뜹니다 (Supabase 주소/키 또는 SQL 실행 여부를 확인하라는 안내 포함)

## AI와 내 판단 (3줄)
1. AI에게 맡긴 일: 전체 코드 작성(화면, 계획/할 일/실행 기록/돌아보기 로직, Supabase 스키마와 RLS 정책, 완료 중복 방지를 위한 원자적 업데이트 설계), 데이터베이스 계약 문서(contracts/pds-schema-v2.json) 작성
2. 내가 직접 판단한 일: (실제로 세운 계획·할 일·실행 기록의 내용, 우선순위, 예상 시간을 실제 값으로 채우는 일 / 돌아보기에서 '고칠 점'을 무엇으로 정할지 / Supabase 프로젝트를 직접 만들고 키를 발급·연결하는 일)
3. AI 제안을 따르지 않은 일(없다면 왜 없었는지): (직접 써보시고 마음에 안 드는 부분—예: 디자인, 문구, 카드 배치 등—이 있으면 여기 적어주세요. 아직 없다면 "실제로 써보기 전이라 아직 없음"이라고 적어도 됩니다)
